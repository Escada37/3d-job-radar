# 3D Job Radar

Версия ищет публикации в русскоязычных Telegram-каналах о работе для художников и в геймдеве. Совпадения определяются по ключевым словам; часть объявлений может оказаться нерелевантной или устаревшей. На странице есть поиск, фильтры и прямые ссылки. Упоминание удалённой работы или России не гарантирует возможность работать из России. Источники и ключевые слова можно изменить в `config.json`.

Это начальная версия: hh.ru, другие площадки, полная история закрытых вакансий и удаление дублей между площадками пока не подключены. Метка «Стилизация» определяется по словам в тексте вакансии и может ошибаться.

## Как запустить автоматически в GitHub

1. Создайте публичный репозиторий и загрузите в его корень все файлы, включая скрытую папку `.github`. Не загружайте токены в файлы репозитория.
2. В Settings → Actions → General → Workflow permissions выберите **Read and write permissions** и сохраните.
3. В Settings → Pages выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. В Actions откройте «Обновить вакансии» и запустите через **Run workflow**. Затем поиск будет запускаться по расписанию примерно раз в три часа; GitHub может задерживать запуски или отключать расписание в неактивном репозитории.
5. Адрес страницы появится в Settings → Pages. Файлы и данные в публичном репозитории видны всем.

## Уведомления Telegram

1. В Telegram откройте официального [BotFather](https://t.me/BotFather), создайте бота командой `/newbot` и сохраните выданный токен. Не отправляйте его в чат и не публикуйте.
2. Откройте своего бота и нажмите Start. Получите числовой chat ID своего личного чата удобным проверенным способом. Код и ID вводите только в GitHub.
3. В GitHub откройте Settings → Secrets and variables → Actions → New repository secret. Создайте два секрета: `TELEGRAM_BOT_TOKEN` с токеном и `TELEGRAM_CHAT_ID` с числовым ID.
4. Запустите workflow снова. Уведомления отправляются о новых вакансиях; вакансии при первоначальном запуске считаются уже известными. Если отправка не удалась, повтор произойдёт при следующем запуске.

Проверяйте вкладку Actions, если обновления остановились. Данные в репозитории не содержат токен Telegram. Сам workflow должен иметь доступ к интернету и разрешение записывать `data.json`.

## Локальное обновление

Установите Node.js версии 22 или новее и выполните `node update.mjs`. Чтобы открыть страницу локально, нужен локальный веб-сервер: открытие `index.html` двойным щелчком может не дать загрузить `data.json`.
